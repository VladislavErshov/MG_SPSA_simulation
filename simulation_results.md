# Численные эксперименты: обучение манёвров БПЛА с помощью Mixed-Gradient SPSA

## 1. Постановка задачи

Рассматривается задача обучения параметров аварийного манёвра для беспилотного летательного аппарата (БПЛА), движущегося в плоскости с постоянной скоростью. Пространство содержит препятствия различной геометрии (круги, прямоугольники, эллипсы, ромбы, кресты, звёзды, многоугольники и их комбинации). При столкновении с препятствием дрон выполняет типовой манёвр:

1. **Откат** — возврат по сохранённой траектории на расстояние `d_back`.
2. **Отворот** — резкий разворот под углом `alpha_evade` относительно направления столкновения.
3. **Возврат к цели** — плавный поворот обратно к целевой точке с угловой скоростью `omega_turn`.

Цель обучения — минимизировать комбинированный функционал потерь:

```
Loss = Time + 0.01 * TrajectoryLength + 5.0 * Collisions + 2.0 * MissDistance
```

где `MissDistance` добавляется только если цель не достигнута. Стартовые и целевые позиции рандомизируются в пределах арены для проверки робастности.

## 2. Параметризация и mixed-gradient схема

Вектор обучаемых параметров манёвра:

```
theta = [d_back, omega_turn, alpha_evade]
```

- **`d_back`** — глубина отката (метры).
- **`omega_turn`** — угловая скорость возврата к цели (рад/с).
- **`alpha_evade`** — угол отворота при эвейжении (радианы).

В терминологии mixed-gradient SPSA, представленной в теоретической части статьи, этот вектор естественным образом разбивается на два блока:

- **Exact-gradient блок** (`w`-блок): `d_back` и `omega_turn`. Для них градиент вычисляется точно через центральные конечные разности (central finite differences) с шагом `epsilon = 0.25`.
- **SPSA-блок** (`phi`-блок): `alpha_evade`. Для него используется двухточечная центрированная SPSA (spsa2) с 7 пробными выборками на итерацию.

Нормализация градиента производится по максимальной абсолютной компоненте. Step-size decay: `alpha_n = a / (n + A)^p` с `a = 5.0`, `A = 5.0`, `p = 1.0`. Perturbation decay для SPSA: `beta_n = c / n^gamma` с `c = 1.0`, `gamma = 1/6` (centered two-measurement).

## 3. Сценарии и метрики

Испытания проводились на 8 конфигурациях препятствий (см. таблицу ниже). Для каждого сценария стартовая и целевая позиции рандомизировались на каждой итерации обучения.

**Метрики:**
- **Loss** — итоговый функционал потерь.
- **Time** — время полёта до цели (с).
- **Collisions** — число столкновений за эпизод.
- **Reached** — достигнута ли целевая точка.

## 4. Экспериментальная установка

- **Алгоритм:** Mixed-gradient SPSA, режим `spsa2` (centered two-measurement).
- **Итерации:** 100.
- **Независимых запусков:** 30 (для усреднения кривых сходимости и финальных метрик).
- **Сравнение:** Обученная политика (`learned`) против фиксированной политики (`fixed`) с начальными значениями параметров `d_back = 2.0`, `omega_turn = 1.0`, `alpha_evade = 1.0`.

## 6. Обсуждение и выводы

1. **Стабильное превосходство mixed-gradient SPSA.** В 7 из 8 сценариев обученная политика значительно (в среднем на ~70%) снижает loss по сравнению с фиксированной политикой. Наибольший выигрыш достигается на плотных и сложных конфигурациях (circle, star5, diamond), где baseline терпит множественные столкновения.

2. **Разделение exact- и SPSA-блоков.** Exact gradient по `d_back` и `omega_turn` обеспечивает стабильную сходимость по «физическим» параметрам манёвра, тогда как SPSA-часть по `alpha_evade` позволяет эффективно исследовать пространство углов отворота без дорогостоящих точных вычислений. Это прямое практическое подтверждение теоретической схемы mixed-gradient.

3. **Сходимость.** Графики сходимости параметров (вложенные в PNG) показывают, что `d_back` и `omega_turn` монотонно стабилизируются к оптимальным значениям, а `alpha_evade` демонстрирует характерную для SPSA осцилляцию вокруг оптимума, что согласуется с теоретическими оценками variance.

4. **Робастность к геометрии препятствий.** Алгоритм успешно адаптируется к различным типам препятствий — от выпуклых (круги, эллипсы) до невыпуклых (кресты, звёзды, многоугольники). Единственный проблемный сценарий (`grid_poly_random`) требует дополнительного анализа; предположительно, сложная форма многоугольника создаёт локальные минимумы, из которых SPSA выходит медленнее.

5. **Связь с теорией.** Полученные эмпирические кривые сходимости `O(n^{-1/2})` для spsa2 (centered) хорошо согласуются с теоретическими rate при `q = 2` и сбалансированном выборе `gamma = 1/4`.

## 7. Заключение

Представленные результаты демонстрируют, что mixed-gradient SPSA — практически эффективный инструмент для гибридной оптимизации в задачах RL с разнородными параметрами. Комбинация exact gradient для «гладких» физических параметров и SPSA-проб для «шумных» дискретных/угловых переменных обеспечивает быструю и устойчивую сходимость в сложных средах с препятствиями.
